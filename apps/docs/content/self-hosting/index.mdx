# Self-Hosting

This section is for the **Operator** — the person who controls a Platypus
deployment: its process environment, compose files, and infrastructure. It also
covers the setup that makes an installation usable at all, such as connecting an
AI vendor and letting people in.

Platypus runs as two services — a backend API and a frontend web app — backed by
PostgreSQL 17 with the `pgvector` extension. The published Docker images stand the
whole stack up with a single `docker compose up`.

Neither service terminates TLS and self-serve sign-up cannot be disabled, so read
[Running in production](/self-hosting/production) before anyone else uses it.
