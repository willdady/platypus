# Reference

Exhaustive, lookup-oriented reference material. These pages enumerate every
configuration option as flat tables — they are the source-of-truth lists, not a
guided walkthrough.

For the narrative "how do I configure this for my deployment" story — TLS,
storage, providers, the sandbox overlay — see
[Self-Hosting](/self-hosting). This section is what you reach for when you
already know roughly what you want and need the exact variable name, default, or
whether it's required.

## Reference describes the present tense

These pages say what a setting does **now**. They don't say what it used to be
called, when it changed, or what replaced it.

That belongs on [Upgrading](/self-hosting/upgrading), which is organised by the
version you're coming from — the only place a reader is actually asking a
historical question. A lookup page that accumulates "the former `X` is removed"
lines slowly becomes a changelog, and then the current value is the hard thing to
find on it.

Same rule for explanations: if a setting needs more than a table cell, the
narrative lives once in [Self-Hosting](/self-hosting) and this page links to it.
